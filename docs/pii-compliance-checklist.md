## 1. 现行技术控制（代码证据）

| 控制 | 实现 | 证据 |
| --- | --- | --- |
| 证件号加密 | AES-256-GCM；`iv(12)‖tag(16)‖ciphertext` | `apps/server/src/utils/crypto.ts` |
| 查重 | HMAC-SHA256（`id_number_hash`），唯一约束 | `apps/server/src/modules/guests/`、`prisma/schema.prisma` |
| 明文暴露 | API 仅返回掩码（前 1 后 1，中间 `*`） | `guests` service/DTO；前端仅展示 `idNumberMasked` |
| 修改限制 | 证件号创建后不可修改（改证件=新档案） | `guests.service.ts`；A-16 |
| 日志 | pino redact 覆盖证件号、密码、会话等 | `utils/logger.ts`；日志测试 |
| 删除 | 无物理删除接口；历史交易外键 RESTRICT | `guests` 模块；数据库设计 |
| 备份 | 运维备份含 PII，需加密存放/限制访问 | `docs/deployment.md` §5 |
