## 1. 现行技术控制（代码证据）

| 控制 | 实现 | 证据 |

## 2. 书面结论（2026-10-18 业主/授权代表电子确认）

| 事项 | 结论 |
| --- | --- |
| 客人档案保留 | 最后一次退房后 **3 年**；到期匿名化姓名、手机号、证件号、备注；保留 `guest id` 关联历史订单/财务记录。无历史交易的档案可删除。 |
| 入住/订单/财务 | **10 年**；保留最小化 PII；最终以财务/税务要求为准。 |
| 审计/安全日志 | **1 年**；不少于 6 个月。 |
| 删除/匿名化 | 不物理删除已入账交易；客人 PII 到期匿名化；数据主体请求由前台/管理员人工受理，核验身份并留痕。 |
| 掩码口径 | 证件号维持前 1 后 1；手机号、姓名仅对已登录的 `ADMIN/RECEPTIONIST` 展示，不做额外掩码。 |
| 密钥管理 | 每年评审；泄露/人员变动立即轮换；轮换前必须完成离线重加密工具（当前未实现）。当前暂缓上线期间不轮换。 |
| 访问权限 | 仅 `ADMIN/RECEPTIONIST` 可查询客人档案；保留现有登录/操作审计；查询审计列为后续增强。 |
| 跨境/第三方 | 无跨境、无 OTA/支付第三方；后续接入需重新评审。 |
| 法务依据 | 入住时隐私告知 + 同意/合同基础；提供数据主体权利联系渠道；员工培训。 |
| 备份 | 备份加密存放、限制访问；恢复演练已通过（2026-10-18）。 |

> 以上为业主/授权代表电子确认的工程/业务口径；合规/法务独立签字待补。当前生产已暂缓，不承载真实客人数据。
