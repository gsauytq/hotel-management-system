### 1.1 证据索引（Q-02 / Q-03）

- **Q-02 Prisma 7 兼容性**
  - 依赖版本：`apps/server/package.json`（`@prisma/adapter-mariadb`、`@prisma/client`、`prisma` 均为 `7.10.1`）；`pnpm-lock.yaml` 已锁定。
  - 真实数据库：CI `integration` job 使用 `mysql:8.4` service，执行 `prisma migrate deploy` 后运行 `pnpm --filter @hms/server test:integration`；日志显示 **249 passed / 35 files**。其中真库用例位于 `apps/server/tests/integration/`（auth、users、guests、rooms、bookings、stays、orders、并发/容量/约束等）。
  - CI 运行：https://github.com/gsauytq/hotel-management-system/actions/runs/39084516436 （`integration` job 成功）。
  - 说明：249 为 integration job 的总用例数（该 job 同时包含 server 单测与真库用例），并非全部 249 条都只测集成层。
- **Q-03 Node 22 锁定**
  - CI：`.github/workflows/ci.yml:18-20` 与 `:86-88` 固定 `node-version: '22.22.0'`。
  - 引擎约束：根 `package.json` 的 `engines.node` 为 `>=22.12.0 <23`。
  - 生产镜像：`apps/server/Dockerfile`、`apps/web/Dockerfile` 使用 `node:22-bookworm-slim`。
  - 依赖管理：`packageManager` 固定 `pnpm@12.6.0`，CI 显式安装同版本。

> 以上证据仅证明技术兼容性与版本锁定；**不构成对 Q-02/Q-03 的业务批准**，仍需业主确认关闭。
